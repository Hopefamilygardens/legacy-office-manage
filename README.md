# Legacy Office Manager

Progressive Web App frontend for the Legacy Office Manager, built with SvelteKit + TypeScript.

## Stack
- SvelteKit
- TypeScript
- PWA (service worker + web manifest)

## Development
- Install dependencies: npm install
- Start dev server: npm run dev
- Build for production: npm run build

## Notes
This repository is the permanent, GitHub-backed home of the frontend. Every change is committed directly to GitHub.
