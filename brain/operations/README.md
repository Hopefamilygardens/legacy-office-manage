# Operations

This folder contains day-to-day operational processes, runbooks, and procedures for Legacy Office Manager.

## Purpose

- Document recurring processes and workflows
- Provide runbooks for common operational tasks
- Record environment setup and deployment procedures
- Capture incident response and on-call procedures

## Governing Authority

The **Constitution** (`../constitution/LEGACY_OS_CONSTITUTION.md`) is the highest authority. All operational procedures must comply with its standards.
