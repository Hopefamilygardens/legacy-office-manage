# Templates

This folder contains reusable document and code templates for Legacy Office Manager.

## Purpose

- Provide standard templates for common Brain documents (ADRs, runbooks, project briefs)
- Offer code scaffolding templates and snippets
- Ensure consistency and completeness across recurring document types
- Reduce friction for contributors creating new content

## Governing Authority

The **Constitution** (`../constitution/LEGACY_OS_CONSTITUTION.md`) is the highest authority. All templates must comply with its principles and the standards defined in `../standards/`.
