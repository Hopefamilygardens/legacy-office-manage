# Constitution

This folder contains the governing Constitution for the Legacy Office Manager repository and Brain.

## Contents

- [`LEGACY_OS_CONSTITUTION.md`](LEGACY_OS_CONSTITUTION.md) — The authoritative Constitution document

## Purpose

The Constitution defines the rules, principles, and standards that govern all work in this repository. It is the highest authority and must be read before any analysis, planning, or code change is made.

No change to the Constitution may be made silently. Any amendment must be clearly communicated and recorded.

## Governing Authority

This folder **is** the governing authority. All other Brain sections and all agents defer to the Constitution.
