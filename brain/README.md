# Legacy Brain

The Legacy Brain is the organizational knowledge base for Legacy Office Manager. It is the single source of truth for decisions, standards, strategy, and institutional knowledge.

## Structure

| Folder | Purpose |
|---|---|
| [constitution/](constitution/) | The governing Constitution — highest authority in this repository |
| [governance/](governance/) | Roles, responsibilities, and decision-making processes |
| [strategy/](strategy/) | Vision, goals, and roadmaps |
| [operations/](operations/) | Day-to-day operational processes and runbooks |
| [departments/](departments/) | Department-specific knowledge and context |
| [projects/](projects/) | Active and planned project documentation |
| [standards/](standards/) | Coding, design, and process standards |
| [knowledge/](knowledge/) | Reference material, research, and how-tos |
| [decisions/](decisions/) | Architectural and strategic decision records (ADRs) |
| [history/](history/) | Historical context, past decisions, and lessons learned |
| [templates/](templates/) | Reusable document and code templates |
| [archive/](archive/) | Superseded or retired content kept for reference |

## Governing Authority

The **Constitution** (`constitution/LEGACY_OS_CONSTITUTION.md`) is the highest authority in this repository. All agents, contributors, and processes must read and comply with it before making changes.
