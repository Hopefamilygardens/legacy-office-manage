# Departments

This folder contains department-specific knowledge, context, and documentation for Legacy Office Manager.

## Purpose

- Capture knowledge unique to each department or team
- Document department-level processes and conventions
- Provide context for cross-functional work
- Record department-specific tooling and integrations

## Governing Authority

The **Constitution** (`../constitution/LEGACY_OS_CONSTITUTION.md`) is the highest authority. All department documentation must align with its principles.
