# Standards

This folder defines the coding, design, and process standards for Legacy Office Manager.

## Purpose

- Document coding conventions and style guides
- Define design system and UI/UX standards
- Establish testing and quality standards
- Record process standards for contributions and reviews

## Governing Authority

The **Constitution** (`../constitution/LEGACY_OS_CONSTITUTION.md`) is the highest authority. All standards must be consistent with its principles and must not contradict it.
