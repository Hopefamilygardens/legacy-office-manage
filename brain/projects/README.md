# Projects

This folder documents active and planned projects for Legacy Office Manager.

## Purpose

- Track project scope, status, and ownership
- Record project goals, milestones, and success criteria
- Capture risks, dependencies, and open questions
- Provide a historical record of completed projects

## Governing Authority

The **Constitution** (`../constitution/LEGACY_OS_CONSTITUTION.md`) is the highest authority. All project documentation must comply with its standards.
