# Archive

This folder contains superseded, retired, or deprecated content kept for reference purposes.

## Purpose

- Preserve retired documents, processes, and decisions that are no longer active
- Provide a historical reference without cluttering active sections
- Maintain an audit trail for content that has been replaced or removed from the main Brain

## Usage

Content in this folder is **not authoritative** and should not be followed as current guidance. Always check the active Brain sections for current standards and processes.

## Governing Authority

The **Constitution** (`../constitution/LEGACY_OS_CONSTITUTION.md`) is the highest authority. Archived content is retained for historical reference only.
